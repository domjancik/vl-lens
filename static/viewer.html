 A DIFFERENT VIEW OF YOUR PATCH

Keep the context.

VL Lens reads saved VL XML and draws its nodes, pins, pads, links and nested regions. Use the document browser or drop your own .vl files.

Explore

Enter definitions, choose operations, inspect defaults and trace hidden or feedback links.

Correlate

See original XML line excerpts and matching attributes or contexts in this repository’s C# export.

This is a structural viewer, not gamma’s compiler or runtime. Node labels and pins are approximated from saved XML. Operation connectivity is not an execution schedule; type and dependency hints are not verified resolutions.

Opened files are parsed by the viewer server. There are no save, compile or execution actions.
